Detailed Description

API of the Ras. A simple, generic return address stack. It does not care at all about wrong predictions.

It does not checks wether the branch is a return on queries. Clients should make this check before sending a query request. It always responds with a ResponseTakeToAddress. It accepts the following parameters:

  • size (required): integer > 0, sets the ras buffer size.
  • sendTo: Component<PredictorPacket>, if exists, the Ras sends responses to this component instead of in the response channel.
