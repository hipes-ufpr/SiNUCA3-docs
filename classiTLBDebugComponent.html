◆ Configure()

int iTLBDebugComponent::Configure ( Config config)
virtual

This method should be declared here so the simulator can send config parameters.

This method is called if the config file defines a configuration parameter for the component. Again, non-zero should be returned on error and the component is responsible for printing a proper error message.

Parameters
parameterThe name of the parameter provided.
valueThe value of the parameter provided.
Returns
Non-zero on error, 0 otherwise.
