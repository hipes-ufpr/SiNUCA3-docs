Detailed Description

Class implementation of the static trace reader.

This file defines the StaticTraceReader class which encapsulates the static trace file and read operations. It is allows one to open a static trace, read its header and the subsequent records stored. No dedicated buffering is done because the file is already mapped to virtual memory.
