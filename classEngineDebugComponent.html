Detailed Description

A component that serves to debug the engine itself.

The component will log with SINUCA3_DEBUG_PRINTF it's parameters along with their values. If passed the parameter "failNow" with any value, the method SetConfigParameter will return with failure. If passed the parameter "failOnFinish", the method FinishSetup will return with failure.

int EngineDebugComponent::Configure ( Config config)

This method should be declared here so the simulator can send config parameters.

This method is called if the config file defines a configuration parameter for the component. Again, non-zero should be returned on error and the component is responsible for printing a proper error message.
